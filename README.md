## Acoustic Architecture

- **Binaural HRTF 3D Panner**: Web Audio `PannerNode` with `panningModel: 'HRTF'`, simulating head-related transfer function for genuine 3D acoustic immersion on AirPods Pro 3 and high-end stereo headphones.
- **Ambient Drone Generator**: Dual sine & triangle oscillators tuned to `55Hz (A1)` and `110Hz (A2)`.
- **Force Touch Sub-Bass**: Dedicated `36.7Hz (D1)` sub-bass oscillator activated proportionally by trackpad pressure.
- **Dynamic Biquad Filter**: Real-time cutoff modulation sweeping between `260Hz` and `6000Hz`.
- **Audio Analyser FFT**: 64-band frequency analyzer driving real-time 3D geometry vibration and canvas visualizer waveforms.
- **Synthesizer Voice Matrix**: Three-octave polyphonic voice allocator with selectable waveforms (Sine, Triangle, Sawtooth, Square) and envelope modulation.
- **DynamicsCompressor Limiter**: Prevents clipping at high master volume (threshold: -6dB, knee: 3dB, ratio: 12:1, attack: 2ms, release: 150ms).
- **Sidechain Ducking Bus**: GainNode between bass elements and master output; kick triggers 8ms duck to 0.05 gain with 80ms release for Amelie Lens-style pumping.
- **High-Shelf Presence EQ**: +4dB boost at 8kHz for hat and percussion clarity on headphones.
- **Atmospheric Noise Texture**: Looping 2-second white noise buffer through genre-specific BiquadFilter (LP 200Hz for techno rumble, BP 3kHz for DnB hiss, LP 80Hz for dubstep sub-feel).
- **Rumble Kick Engine**: Exponentially-decaying noise buffer, lowpass filtered at 120Hz, driven through WaveShaper distortion for Ben Klock-style sub-rumble tails.
- **FM Synthesis Bass**: Carrier + modulator oscillator pair with sweeping modulation depth connected to carrier frequency AudioParam for Mefjus/Noisia metallic wobble.
- **Ring Modulation Percussion**: Inharmonic oscillator pairs (340Hz + 587Hz) for Kobosil-style industrial metallic stabs.
- **Dual 303 Stacking**: Primary + detuned (+7 cents) acid voices with screaming resonance Q up to 18.0 for 999999999-style raw acid.
- **Advanced Formant Growl**: Triple oscillator (saw + square sub-octave + inharmonic ring-mod), dual-stage bandpass vowel sweep, square-wave LFO amplitude chop for Virtual Riot/Must Die! sound design.
- **808 Sub Oscillator**: Pure sine with gentle pitch bend and long sustain envelope for Trampa-style devastating sub pressure.

## Technology Stack

- **Core**: Vanilla HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom properties, 3D transforms, Glassmorphism).
- **3D Graphics**: [Three.js](https://threejs.org/) (r128).
- **Sound Synthesis**: Native Browser [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) (HRTF Spatial Panner, BiquadFilter, AnalyserNode, Oscillators).
- **Hardware Integrations**: Apple WebKit Force Touch API (`webkitmouseforcechanged`), W3C Pointer Events.
- **Typography**: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
- **Hosting**: GitHub Pages (Zero build step, 100% static & blazing fast).
