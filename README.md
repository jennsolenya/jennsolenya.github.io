## Interactive Mechanics & Controls

| Input | Target | Action |
| :--- | :--- | :--- |
| **Cursor Move** | Viewport | Casts a radial spotlight revealing hidden grid coordinates and cosmic dust. Modulates audio filter cutoff frequency and adds +0.025 entropy. |

| **Pinch / Scroll** | 3D WebGL Canvas | Zooms camera closer (`z: 3.8`) or further into the deep void (`z: 11.5`) (+0.03 entropy). |
| **Trackpad Force** | Mac Trackpad | Calibrated analog pressure: light touch (0-49%), click (50%), deep press (50-100%). Surges spotlight radius, sub-bass, and wireframe scale. |
| **Click / Drag** | Particle Collider Canvas | Shapes the gravitational attractor well; sends kinetic shockwaves across 2,500 particles (+0.12 entropy). |

| **Pills & Action Buttons** | Collider Lab Controls | Switches between Inflation, Vortex, Accretion, and Quantum Foam modes; triggers Big Bang pulses or field resets. |
| **Cutoff & Res Sliders** | Sound Studio Console | Dynamically modulates master lowpass filter cutoff ($200\text{Hz}-12\text{kHz}$) and resonance $Q$ ($0.1-18.0$) in real time. |
| **Genre Selector Pills** | Sound Console | Instantly shifts between 135 BPM Acid Techno, 174 BPM Neurofunk DnB, 145 BPM Skrillex Bass, 70 BPM Ambient, and The Big Bounce. |

## Sound Architect Profiles & Cosmological Epochs

The **EPOCH // COSMIC GENRE** selector allows manual time-warping between the 5 cosmological sound architectures:

1. **`01 // ACID WAREHOUSE` (135 BPM - Techno)**:
   - *Artists*: Charlotte de Witte, Amelie Lens, 999999999.
   - *Acoustics*: 909 transient kick attacks (1200Hz click &rarr; 42Hz sub boom), distorted Roland TB-303 acid bassline squelches ($Q=9.0\dots 13.5$ filter sweeps through WaveShaper saturation), open off-beat 909 hats, and 16th rolling accents with pitch slides.
   - *Visuals*: High-speed crystalline wireframe rotation with acid-pulsed vertices.
2. **`02 // DNB NEUROFUNK` (174 BPM - Drum & Bass)**:
   - *Artists*: Chase & Status, Noisia.
   - *Acoustics*: Syncopated Amen-style breakbeat pattern (kicks on 0, 7, 10; snares on 4, 12), rolling shuffled 16th hats, and detuned Reese sub-bass with sweeping resonant lowpass filters.
   - *Visuals*: Rapid kinetic oscillation and expanded field scale.
3. **`03 // SKRILLEX BASS` (145 BPM - Heavy Bass & Dubstep)**:
   - *Artists*: Skrillex, Space Laces.
   - *Acoustics*: Half-time riddim kick-snare grid, explosive 808 sub drops, and aggressive formant throat vowel growls ($450\text{Hz}\to 2600\text{Hz}\to 320\text{Hz}$ bandpass modulation through analog distortion).
   - *Visuals*: High-amplitude audio-reactive mesh deformation and intense visual shockwaves.
4. **`04 // AMBIENT VOID` (70 BPM - Deep Meditation)**:
   - *Acoustics*: Deep sub-frequency meditation (`36.7Hz D1`), expansive spatial reverb chimes, and minimal celestial drones.
   - *Visuals*: Compressed singularity core in tranquil suspension.
5. **`05 // THE BIG BOUNCE` (128 BPM - Rebirth)**:
   - *Acoustics*: A descending pitch glissando simulating cosmic crunch, followed by a 1-beat vacuum of total silence, rebounding into a 5-voice celestial rebirth chord.
   - *Visuals*: Complete contraction and explosive rebound pulsation.

Clicking any profile pill immediately activates the audio engine, sets the tempo, alters oscillator waveforms, and warps the 3D visual scale to match the selected cosmic era.

## Acoustic Architecture

- **Binaural HRTF 3D Panner**: Web Audio `PannerNode` with `panningModel: 'HRTF'`, simulating head-related transfer function for genuine 3D acoustic immersion on AirPods Pro 3 and high-end stereo headphones.
- **Ambient Drone Generator**: Dual sine & triangle oscillators tuned to `55Hz (A1)` and `110Hz (A2)`.
- **Force Touch Sub-Bass**: Dedicated `36.7Hz (D1)` sub-bass oscillator activated proportionally by trackpad pressure.
- **Dynamic Biquad Filter**: Real-time cutoff modulation sweeping between `260Hz` and `6000Hz`.
- **Audio Analyser FFT**: 64-band frequency analyzer driving real-time 3D geometry vibration and canvas visualizer waveforms.
- **Synthesizer Voice Matrix**: Three-octave polyphonic voice allocator with selectable waveforms (Sine, Triangle, Sawtooth, Square) and envelope modulation.

## Technology Stack

- **Core**: Vanilla HTML5, Vanilla JavaScript (ES6+), Vanilla CSS3 (Custom properties, 3D transforms, Glassmorphism).
- **3D Graphics**: [Three.js](https://threejs.org/) (r128).
- **Sound Synthesis**: Native Browser [Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API) (HRTF Spatial Panner, BiquadFilter, AnalyserNode, Oscillators).
- **Hardware Integrations**: Apple WebKit Force Touch API (`webkitmouseforcechanged`), W3C Pointer Events.
- **Typography**: [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
- **Hosting**: GitHub Pages (Zero build step, 100% static & blazing fast).
